三条曲线解释这个库的三个主张：忘得慢、放指针、先问记不记得。

1 · 幂律遗忘，而不是指数衰减

R(t) = (1 + t/S)−0.7。同一记忆，S 越大忘得越慢（salience 高的 S 更大）。拖动天数看三条曲线的留存。

第 30 天

2 · 会话越长，指针越省

naive 每轮重发全文，成本随轮数线性上升；mnemo 每轮只放指针，近似恒定。交叉点在 11 轮左右。

会话 16 轮
